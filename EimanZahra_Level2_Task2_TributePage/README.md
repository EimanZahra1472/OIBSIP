# Tribute Page - Imran Khan

## Description
A beautiful tribute page dedicated to Imran Khan - legendary cricketer, philanthropist, and former Prime Minister of Pakistan. This page honors his life, achievements, and legacy.

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, CSS Variables, Animations)
- JavaScript ES6+ (Intersection Observer, Smooth Scroll)
- Font Awesome Icons

## File Structure
Level2_Task2_TributePage/
├── index.html # HTML structure
├── style.css # All styling
├── script.js # JavaScript interactions
└── README.md # Documentation

## Features
- **Hero Section** - Imran Khan's name, title, quote, and stats
- **Biography** - Personal and professional life details
- **Cricket Career** - Stats, highlights, and timeline
- **Achievements** - Major life accomplishments
- **Politics Section** - Political journey and vision
- **Gallery** - Image collection with captions
- **Famous Quotes** - Inspirational quote section
- **Learn More Link** - External Wikipedia link
- **Responsive Design** - Mobile-friendly layout
- **Smooth Animations** - Scroll-triggered animations

## How to Run
1. Save all files in the same folder
2. Open `index.html` in any modern browser
3. No server or dependencies required

- **Cricket Stats:** 88 Tests, 362 Wickets, 1992 World Cup Winner
- **Achievements:** ICC Hall of Fame, Shaukat Khanum Hospital, Namal University
