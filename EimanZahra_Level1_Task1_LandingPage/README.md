# Level 1 – Task 1: Landing Page

## Description
A fully responsive landing page for a fictional digital agency called **Nexora**. Demonstrates core HTML & CSS layout techniques including Flexbox, CSS Grid, custom properties, and responsive design.

## Technologies Used
- HTML5 (semantic markup)
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Google Fonts (Inter + Space Grotesk)

## Features
- Fixed navigation bar with smooth scroll links
- Hero section with headline, CTA buttons, and stat cards
- Stats strip with key metrics
- Services section — 6 cards using CSS Grid auto-fit
- About section with a two-column layout and skill bars
- Testimonials section with client quote cards
- Call-to-action banner
- Footer with 4-column layout and branding
- Fully responsive down to 480px (mobile-first breakpoints)
- CSS custom properties for consistent theming

## How to Run
1. Open `index.html` in any modern browser — no build step required.
