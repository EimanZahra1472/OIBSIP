# Portfolio - Eiman Zahra

## Description
A professional portfolio website showcasing Eiman Zahra's skills, projects, and experience as an AI/ML student at NUST. The portfolio highlights technical expertise in Machine Learning, Full-Stack Development, and Mobile App Development.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- No external frameworks - pure CSS

## Features
- **Responsive Navigation** - Fixed navbar with smooth scroll to sections
- **Hero Section** - Introduction with contact info and CTA buttons
- **Skills Grid** - Organized by categories (Languages, ML/AI, Frontend, Backend & Tools)
- **Projects Showcase** - Cards displaying key projects from IntelliMart to Sentiment Analysis
- **Experience Timeline** - Internships at Sines, FlyRank AI, and GAO TEKUSA
- **Education & Certifications** - NUST AI degree + Harvard CS50, Andrew Ng ML Specialization
- **Contact Section** - Email, phone, location with social links
- **Fully Responsive** - Mobile-friendly layout with breakpoints at 768px

## Project Highlights Featured
1. **IntelliMart** - E-commerce with ML product classifier (89.54% accuracy)
2. **Sentiment Analysis** - 3-model comparison (Classical ML, BERT, LLaMA3)
3. **Real-Time Messaging** - WhatsApp clone with Socket.io
4. **Hostel Management** - Full-stack with SQL
5. **Health Monitoring** - C++ OOP implementation

## How to Run
1. Download both files to `Level1_Task2_Portfolio/` folder
2. Open `index.html` in any modern browser
3. No build steps or dependencies required
